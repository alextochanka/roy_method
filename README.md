О проекте
Программа реализует метод роя частиц (Particle Swarm Optimization, PSO) для глобальной оптимизации многомерных функций. Логика алгоритма один в один перенесена из Delphi-версии (PSO_Engine.pas), а интерфейс повторяет компоновку исходной VCL-формы PartialSwarmInt.

Дополнительно к оригиналу добавлен флажок «Сравнить classic vs hybrid», который запускает оба режима на одинаковых параметрах и накладывает графики сходимости друг на друга — удобно для отчётов и сравнительного анализа.

Алгоритмы
Classic PSO
Классический роевой алгоритм:

Инициализация роя случайными позициями в диапазоне [-SearchRange, +SearchRange] и скоростями в [-MaxVelocity, +MaxVelocity].

На каждой итерации скорость частицы обновляется по формуле:

text
v = w·v + c1·r1·(pbest − x) + c2·r2·(gbest − x)
где w — вес инерции, c1/c2 — коэффициенты самоуверенности и социальности, r1/r2 — случайные числа из [0, 1].

Скорость ограничивается MaxVelocity, позиция — SearchRange (если штрафы выключены).

Личный рекорд частицы (pbest) и глобальный рекорд роя (gbest) обновляются при улучшении.

Опционально поддерживаются:

Адаптивный инерционный вес — линейно убывает от InertiaStart до InertiaEnd по ходу итераций.

Штрафная функция — запрещает вылет за границы через штраф PenaltyRatio × отклонение вместо жёсткого клиппинга.

Hybrid PSO
Тот же PSO плюс механизм мутаций для выхода из локальных минимумов:

Если лучшее решение не улучшается MaxIterWithoutImprovement итераций подряд — запускается мутация.

Худшая половина роя перезапускается:

первая мутация — локальный поиск вокруг глобального лучшего (MutationLocalRadius = 0.5),

последующие — полная случайная реинициализация в диапазоне поиска.

После MUTATION_AMT = 3 безуспешных мутаций счётчик сбрасывается, и алгоритм продолжает обычную работу.

Оба режима реализованы в одном классе PSOEngine и переключаются параметром use_mutations.

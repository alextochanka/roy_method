📝 Описание
Приложение с графическим интерфейсом для решения задач глобальной оптимизации с использованием Роевого метода (Particle Swarm Optimization, PSO).

Программа позволяет находить глобальные минимумы для 8 классических тестовых функций, широко используемых в области вычислительных процессов.

💡 Приложение реализовано на Delphi 12+ с использованием VCL и ориентировано на платформу Windows.

🎯 Целевые функции
№	Функция	Название	Особенности
1	f(x) = Σ xᵢ²	Сфера	🟢 Гладкая, унимодальная
2	f(x) = 10n + Σ(xᵢ² − 10cos(2πxᵢ))	Растригин	🔴 Много экстремумов
3	f(x) = Σ [100(xᵢ₊₁ − xᵢ²)² + (1 − xᵢ)²]	Розенброк	🟡 «Овраг», сложный для поиска
4	f(x) = −Σ xᵢ · sin(√|xᵢ|)	Швефель	🔴 Много локальных минимумов
5	f(x) = −20exp(−0.2√(Σxᵢ²/n)) − exp(Σcos(2πxᵢ)/n) + 20 + e	Экли	🟡 Плоский, с глубоким минимумом
6	f(x) = sin²(3πx₁) + (x₁−1)²(1+sin²(3πx₂)) + (x₂−1)²(1+sin²(2πx₂))	Леви	🔴 Сильная мультимодальность
7	f(x) = 1 + Σ(xᵢ²/4000) − Πcos(xᵢ/√i)	Гриванк	🟡 Много регулярных минимумов
8	f(x) = (x₁² + x₂ − 11)² + (x₁ + x₂² − 7)²	Химмельблау	🔵 4 глобальных минимума

Сводная статистика — среднее, минимум, максимум, стандартное отклонение.

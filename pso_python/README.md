# PSO на Python (перенос с Delphi)

Перенос программы `Roy` (Delphi/VCL: `PSO_Engine.pas` + `PartialSwarmInt.pas`)
на Python. Сохранены оба алгоритма из оригинала — обычный PSO и гибридный
PSO (с мутациями худшей половины роя при застое) — и добавлена возможность
сравнивать их между собой на одном прогоне, как требовалось для отчёта.

## Установка

```bash
pip install -r requirements.txt
```

(`tkinter` идёт в комплекте со стандартным Python на Windows; на Linux
может понадобиться `sudo apt install python3-tk`.)

## Запуск

```bash
python main.py
```

## Структура

- `test_functions.py` — 29 тестовых функций (21 исходная из Delphi-версии
  + 8 новых: Beale, Booth, Matyas, Zakharov, Easom, Bohachevsky N.2,
  Salomon, Eggholder) с границами поиска для каждой.
- `pso_engine.py` — сам алгоритм: класс `PSOEngine` с режимами
  `use_mutations=False` (classic) и `use_mutations=True` (hybrid),
  адаптивным инерционным весом и штрафной функцией — один в один
  логика из `PSO_Engine.pas`.
- `gui.py` — окно на Tkinter, повторяющее компоновку оригинальной формы
  (параметры слева, таблица прогонов + график сходимости + сводка справа),
  плюс флажок «Сравнить classic vs hybrid».
- `main.py` — точка входа.
